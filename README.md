# Lead Gen Agent
An **AI-powered** system that finds, verifies and delivers business leads **automatically**.

## What This Does
This project automates lead generation for agencies using AI agents.
It saves **10+ hours** of manual work every week.

## How It Works
Each agent does **one job**. Together they build a **full pipeline**.

- Find leads online
- Scrape their website
- Verify their email
- Score the lead
- Push to CRM

## Agents
We have **9 agents** built so far.

- Lead Hunter
- Website Scraper
- Email Verifier
- Data Cleaner
- Lead Scorer

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the agent:

```python
python agent.py
```
